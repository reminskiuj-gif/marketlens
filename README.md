# MarketLens

Вебсайт для перегляду статистики й порівняння **акцій компаній** та **криптовалют** в одному місці.

Сайт має два розділи, «Акції» і «Криптовалюта», між якими можна перемикатися вгорі сторінки. На головному екрані кожного розділу показано лідерів зростання й падіння за обраний період. Користувач може позначити кілька позицій, як у кошику порівняння інтернет-магазину, і побачити їх на одному графіку. Акції та криптовалюту можна змішувати в одному порівнянні.

> **Стан:** етап 1 із 5, виконано приблизно 35%. Зараз сайт працює на тестових даних.

## Як запустити

Збирати чи встановлювати нічого не потрібно, але сторінку треба відкривати через локальний сервер:

```bash
python -m http.server 5500 --directory marketlens
```

Потім відкрийте `http://localhost:5500`. Також підійде розширення **Live Server** у VS Code. Для графіків потрібен інтернет, бо бібліотека Chart.js завантажується з CDN.

## Технології

- **HTML5, CSS3, JavaScript (ES2020)** без фреймворків
- **[Chart.js 4](https://www.chartjs.org/)** для графіків порівняння
- Міні-графіки в таблиці малюються вручну як SVG
- Теми побудовані на CSS-змінних і `prefers-color-scheme`

## Структура проєкту

```
marketlens/
├── index.html                  розмітка сторінки
├── css/
│   └── styles.css              стилі, світла й темна теми
└── js/
    ├── utils.js                форматування чисел і дат, генератор випадкових чисел
    ├── i18n.js                 переклади інтерфейсу (українська, англійська)
    ├── store.js                стан застосунку (обраний розділ, період, порівняння)
    ├── app.js                  точка входу, зв'язує модулі між собою
    ├── data/
    │   ├── assets.js           довідник акцій і криптовалют
    │   └── mockGenerator.js    генерація тестової історії цін
    ├── services/
    │   └── dataService.js      шар даних (у майбутньому — запити до API)
    └── ui/
        ├── components.js       спільні елементи: логотип, бейдж зміни, міні-графік, модальні вікна
        ├── header.js           верхня панель і перемикач розділів
        ├── marketView.js       головний екран: лідери і таблиця
        ├── search.js           пошук
        ├── compareTray.js      нижня панель порівняння
        ├── compareView.js      вікно порівняння з графіком
        └── settings.js         налаштування
```

### Архітектура

```
 Інтерфейс (ui/*)  ──дії──▶  store (стан)  ──події змін──▶  інтерфейс перемальовується
        │
        └──запити──▶  dataService  ──▶  тестові дані (зараз) / API (етап 3)
```

- **Інтерфейс не працює з даними напряму.** Усі запити йдуть через `dataService`, і його методи вже повертають `Promise`, як справжнє API. Щоб перейти на реальні дані, достатньо змінити один файл.
- **Стан зберігається в одному місці** (`store.js`). Модулі підписуються на зміни й оновлюють лише свою частину сторінки.
- **Жодного тексту в коді інтерфейсу.** Усі написи беруться зі словників у `i18n.js` за ключем, наприклад `t('movers.gainers')`. Формат чисел і дат теж залежить від мови: `1 234,56` українською і `1,234.56` англійською. Щоб додати нову мову, достатньо додати ще один словник.
- **Тестові дані відтворювані.** Ціни генеруються моделлю геометричного броунівського руху з фіксованим seed для кожного активу, тому після перезавантаження графіки не змінюються.

## Як працюємо разом (Git)

- Код зберігається в спільному репозиторії на GitHub, обидва учасники в ньому колаборатори.
- Гілка `main` завжди містить робочу версію сайту.
- Кожна задача робиться в окремій гілці, наприклад `feature/asset-page` або `feature/coingecko-api`.
- Зміни потрапляють у `main` через Pull Request, і другий учасник переглядає код перед злиттям.
- Задачі ведемо в GitHub Issues або Projects. Так видно, хто що зробив і скільки залишилось.

# MarketLens

Вебсайт для перегляду статистики й порівняння **акцій компаній** та **криптовалют** в одному місці.

Сайт має два розділи, «Акції» і «Криптовалюта», між якими можна перемикатися вгорі сторінки. На головному екрані кожного розділу показано лідерів зростання й падіння за обраний період. Користувач може позначити кілька позицій, як у кошику порівняння інтернет-магазину, і побачити їх на одному графіку. Акції та криптовалюту можна змішувати в одному порівнянні.

> **Стан:** етап 3 у роботі. Реальні дані підключено повністю: криптовалюта йде з Binance, акції з Finnhub (ціни) і Twelve Data (історія).

## Як запустити

Збирати чи встановлювати нічого не потрібно, але сторінку треба відкривати через локальний сервер:

```bash
python -m http.server 5500 --directory marketlens
```

Потім відкрийте `http://localhost:5500`.

**Ключі API для акцій.** Скопіюйте `js/config.example.js` у `js/config.local.js` і вставте свої безкоштовні ключі з [finnhub.io](https://finnhub.io/dashboard) і [twelvedata.com](https://twelvedata.com/account/api-keys). Файл `config.local.js` не потрапляє в Git. Без ключів акції показуються на тестових даних, а криптовалюта працює й так. Також підійде розширення **Live Server** у VS Code. Для графіків потрібен інтернет, бо бібліотека Chart.js завантажується з CDN.

## Технології

- **HTML5, CSS3, JavaScript (ES2020)** без фреймворків
- **[Chart.js 4](https://www.chartjs.org/)** для графіків порівняння
- **Binance Market Data API** для криптовалют: REST для історії цін і WebSocket для живих цін, ключ не потрібен
- **Finnhub** для акцій: поточні ціни (REST) і живі угоди (WebSocket), безкоштовний ключ
- **Twelve Data** для акцій: історія цін, безкоштовний ключ
- Міні-графіки в таблиці малюються вручну як SVG
- Теми побудовані на CSS-змінних і `prefers-color-scheme`

### Архітектура

```
 Інтерфейс (ui/*)  ──дії──▶  store (стан)  ──події змін──▶  інтерфейс перемальовується
        │
        └──запити──▶  dataService  ──▶  тестові дані (зараз) / API (етап 3)
```

- **Інтерфейс не працює з даними напряму.** Усі запити йдуть через `dataService`, і його методи вже повертають `Promise`, як справжнє API. Тому живі дані для криптовалют підключено без змін в інтерфейсі, і так само підключатимуться акції.
- **Стан зберігається в одному місці** (`store.js`). Модулі підписуються на зміни й оновлюють лише свою частину сторінки.
- **Жодного тексту в коді інтерфейсу.** Усі написи беруться зі словників у `i18n.js` за ключем, наприклад `t('movers.gainers')`. Формат чисел і дат теж залежить від мови: `1 234,56` українською і `1,234.56` англійською. Щоб додати нову мову, достатньо додати ще один словник.
- **Живі ціни.** Історія за період завантажується через REST API Binance (свічки по 1 год, 4 год або 1 день) і кешується. Поточні ціни приходять через WebSocket, і раз на секунду в таблиці оновлюються лише змінені клітинки. Ціна підсвічується зеленим або червоним.
- **Ліміти безкоштовних API.** Finnhub дозволяє 60 запитів на хвилину, тому ціни акцій кешуються в браузері, і повторне відкриття сторінки не витрачає ліміт. Twelve Data дозволяє 8 запитів на хвилину (ми використовуємо 6, із запасом), тому історія завантажується через чергу: перший раз близько 5 хвилин, а позначка показує прогрес, наприклад «історія цін 18/30». Потім історія зберігається в браузері (щоденна на 12 годин, погодинна на 30 хвилин).
- **Стійкість.** Якщо джерело недоступне або ліміт вичерпано, сайт показує останні збережені ціни. Якщо збережених немає, показує тестові дані з відповідною позначкою.
- **Тестові дані відтворювані.** Ціни генеруються моделлю геометричного броунівського руху з фіксованим seed для кожного активу, тому після перезавантаження графіки не змінюються.

## Як працюємо разом (Git)

- Код зберігається в спільному репозиторії на GitHub, обидва учасники в ньому колаборатори.
- Гілка `main` завжди містить робочу версію сайту.
- Кожна задача робиться в окремій гілці, наприклад `feature/asset-page` або `feature/coingecko-api`.
- Зміни потрапляють у `main` через Pull Request, і другий учасник переглядає код перед злиттям.
- Задачі ведемо в GitHub Issues або Projects. Так видно, хто що зробив і скільки залишилось.

## Застереження

Ціни криптовалют (Binance) і акцій (Finnhub) реальні. Капіталізацію криптовалют розраховано приблизно, а капіталізацію акцій — за кількістю акцій станом на листопад 2026. Сайт не є інвестиційною порадою.
